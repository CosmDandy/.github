# Social preview images

1200×630 PNGs for the **Settings → Social preview** field of each repository.
GitHub has no API for that field, so each one is uploaded by hand, once.

They share the visual language of `cosmdandy.dev/assets/og.svg`: black ground,
dot grid, blurred gradient halo, Inter. Sources and the generator live in
`social-preview/src/`.
